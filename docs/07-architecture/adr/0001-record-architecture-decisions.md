# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-22
- Deciders: Architect

## Context
Security decisions must be traceable and justified, and the dev team (coding agent) must be able to follow them.

## Decision
Record each significant decision as a numbered ADR in `docs/07-architecture/adr/` using `0000-template.md`. The dev team follows accepted ADRs and may only propose new ones.

## Consequences
Slight overhead per decision. Gains traceability and a clear record of rejected alternatives.
