# Security Policy

FilterKappi is a hypothetical training project and is not deployed in production.

## Reporting a vulnerability

If you find a vulnerability in this repository, please open a private security
advisory via GitHub ("Security" tab > "Report a vulnerability") rather than a public issue.

## Scope

In scope: code and configuration in this repository.
Out of scope: third-party dependencies (report upstream), anything not hosted by the author.

## Response expectations (exercise targets)

- Acknowledge within 3 days
- Triage and severity rating within 7 days
- Fix or documented mitigation based on severity (Critical 7 days, High 30 days)
